Cada color es un token. Los recuadros punteados son bytes sueltos: trozos de un carácter UTF-8 que el tokenizador no llegó a fusionar.

Entrena el tuyo

Edita el texto de entrenamiento, elige el tamaño del vocabulario y entrena. El resultado se usa en “Mi tokenizador”.

Cómo funciona

  1. Se empieza con 256 tokens, uno por cada byte posible, así que cualquier texto en cualquier idioma se puede representar.
  2. Una expresión regular corta el texto en trozos (palabras, números, signos y espacios) para no mezclar, por ejemplo, una palabra con la coma que la sigue.
  3. Se cuenta qué pareja de tokens consecutivos aparece más, se fusiona en un token nuevo y se repite hasta llegar al tamaño de vocabulario.
  4. Para codificar se aplican las fusiones en el orden en que se aprendieron; para decodificar se juntan los bytes de cada token.

La pestaña GPT-4 usa el vocabulario oficial cl100k_base con este mismo código: las fusiones se reconstruyen a partir de los rangos y los ids coinciden exactamente con los de tiktoken.
